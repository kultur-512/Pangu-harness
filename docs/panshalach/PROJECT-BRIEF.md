# 烛龙项目总览（PROJECT-BRIEF · 2026-09-06 · v0.7.4）

## 一、项目有哪些模块

| 层 | 模块 | 职责 |
|---|---|---|
| 入口 | `src/cli.ts`、`src/server/` | CLI 兼容层（交互 REPL / headless 单任务 / --approval / --resume）+ 统一任务执行器（runAgentTask，三入口共享）+ HTTP/SSE 服务 |
| 交互 | `src/cli/repl/` | 主交互循环（流式渲染、工具实时卡片、Ctrl+C 语义、审批菜单、Tab 补全、模式环）、经典行模式兜底、26 个斜杠命令、输入队列（运行中插话） |
| 意图 | `src/cli/taskIntent.ts` | 三态分类：chat 直接回答 / search 只读限 3 步 / task 完整工程循环——在入口对原始输入分类 |
| 提示 | `PromptBuilder` + `StructuredReasoner` | 每任务提示词组装（硬约束/档位契约/记忆卡/技能/上下文，按 intent 分支）+ 推理模板与工具格式教学 |
| 执行 | `src/loop/VerifyCritiqueLoop` | 单循环 agent 引擎：回合终态语义（completed 真实验证通过 / answered 直接回答 / no-verification 空转；另有 max-steps / consecutive-failures / aborted / error——0.7.4 起模型故障与用户中断严格分离）、真实引擎信号入册、窗口预算裁剪 |
| 工具 | `src/tools/` | 6 件核心工具（bash/read/write/edit/glob/grep）+ MCP 扩展、审批门禁（readonly/default/full 三档+会话 allowlist+持久化）、写前读纪律、文件快照（undo/rewind）、子进程树击杀 |
| 模型 | `src/model/` | 任意 OpenAI 兼容网关接入（provider:model 路由）、native function calling 请求/响应两侧、重试退避、截断防御、推理模型空响应兜底 |
| 记忆 | `src/memory/` | 记忆卡二态语义（注入记账 vs 行为保鲜）、任务成功自动沉淀（refine→save）、注入审计（promptHash/卡号）、压缩血统账本（generation/coveredTurnIds） |
| 会话资产 | `rolloutStore` | append-only JSONL 事件账本：turn/approval/compact/context 事件，支撑 resume/branch/undo/审计回放 |
| 评测 | `scripts/eval/`（develop） | A/B/C(+C4) 消融评测 runner + T1-T5 任务 fixture + 结果 schema + mock smoke |
| 质量设施 | `tests/`（749 例）、两个契约脚本 | 全量测试 + 存储名清理检查 + 保护文件契约检查 |

## 二、项目如何组成（一句话架构）

**一条主线**：用户输入 → 意图分类 → 提示词组装（注入记忆卡）→ 单循环执行（模型↔工具，真实验证信号裁决）→ 任务落定（成功自动沉淀经验卡 + 注入卡行为保鲜）→ 事件账本落盘（可 resume/branch/undo）。
**四个支撑**：多模型网关接入（openPangu 1B/7B 及任意兼容端点）、会话资产（长任务断点续接与压缩）、三档审批安全门、749 例测试 + 契约脚本的质量设施。

## 三、向初学者介绍（概括版）

> 我们做的是一个**能记住你的编码助手**。
>
> 现在的 AI 编程工具有个通病：聊着聊着就忘了你最早定下的规矩。烛龙要解决的就是这个"中期遗忘"——它把每次任务的关键经验写成"记忆卡"，下次类似任务自动带上；你定下的约束、踩过的坑，它会记住并在该用时想起。
>
> 它基于华为 openPangu 模型（本地就能跑），你用自然语言下任务，它读代码、改文件、跑测试，并且**只有测试真通过了才算完成**——不是它自己说完成就算。它分得清你在聊天还是在派活：聊天直接回答，派活才动代码。做错能回退（undo），中断能续接（resume），上下文快满会自动压缩并保留关键信息。
>
> 一句话：**模型负责聪明，烛龙负责可靠。**

### 详细版

**1. 项目定位与进展**
本项目是面向华为命题《基于 openPangu 的记忆增强智能体架构设计与优化》的完整交付：一个以记忆管理为核心的长上下文编码智能体。当前版本 v0.7.4，develop 分支已含全部主线成果，从 clone 到第一条真实任务完成可在 15 分钟内完成。

**2. 核心能力（均已落地主线，有集成测试锁定）**
- **记忆闭环**：任务成功自动沉淀经验卡 → 后续任务按相关性注入 → 卡片被真实使用后刷新保鲜（区分"被看见"与"被使用"）→ 注入全程有审计账本（promptHash + 卡号）。
- **可靠的执行语义**：模型回答、真实验证通过、空转三种结束态严格区分；只有外部验证通过才记为"完成"，防止模型自报完成。意图分类让聊天、搜索、工程任务各走各的通道。0.7.4 起模型/网络故障落独立 error 终态（"任务执行失败"），与用户中断严格分离。
- **长上下文管理**：事件账本 + 血统安全的压缩（中断/回退不丢现场）、按模型真实窗口的预算控制、工具结果超阈值才剪。
- **安全与可回退**：三档审批模式（只读/确认/自动）、写前读纪律、文件快照一键回退、子进程中断击杀。
- **工程化**：749 例自动化测试全绿；两个契约脚本防架构破坏；本地一键部署（npm link + LM Studio）；文档 19 份（docs/panshalach，另 solution/ 系列 10 篇）含提交物初稿（SUBMISSION/DEPLOY-CN）。
