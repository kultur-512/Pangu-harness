# T2 — 跨文件关联（Cross-File Context）

## 目标
验证模型在多文件代码库中能否追踪跨文件引用（类型定义、函数调用、import 链）。

## 场景定义
- 输入：3-10 个文件的代码库，issue 涉及跨文件修改
- 期望：模型能正确识别所有需要修改的位置

## 验收 Rubric
| 维度 | 评分 |
|---|---|
| 跨文件定位准确率 | 正确识别需修改文件数 / 实际需修改文件数 |
| 引用追踪深度 | 解析 import / 调用的层数 |
| 误改率 | 修改了不应修改的文件数 |
